# IP Camera Viewer

This repository contains the Android application in [`IPCameraViewer/`](IPCameraViewer/). It supports RTSP and HTTP MJPEG feeds, ONVIF discovery, manual NVR channel templates, up to nine cameras, and phone/Android TV controls.

Start with the [application README](IPCameraViewer/README.md) for setup and use, or [architecture notes](IPCameraViewer/ARCHITECTURE.md). The root GitHub Actions workflow builds the nested Android project and uploads its debug APK.
